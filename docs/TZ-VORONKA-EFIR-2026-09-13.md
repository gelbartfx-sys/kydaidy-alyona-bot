# ТЗ: воронка «эфир-воркшоп» (допрос Кая 13.09.2026)

Источник: рукописная схема Кая (шаги 1–5) + 7 раундов допроса. Статус: ждёт ✅ Кая.

## Путь человека
1. **Контент** (ЦЕХ): Reels/Pinterest, доли 10% результаты тестов · 10% боль · 10% личный опыт · 70% истории. Ссылки с метками на сайт.
2. **Сайт kydaidy.com → запись на эфир.** Каждый день в одно время. Двери: сайт, бот, канал @kydaidy — одна запись.
3. **Эфир-воркшоп**: запись Алёны 40–60 мин, идёт «как живой» (комната как `/efir` в ЦЕХе: без перемотки, опоздавший в середину). Смотреть: Mini App, сайт, дальше другие площадки. Структура: проблема → решение есть → способы → показ решения + соцпруф → вера + анонс разбора. **Цену на эфире не называем.**
4. **Сразу после эфира**: тест 2 → приложение (дневник, 7 дней). Всё это время «Алёна рядом»: кружки и аудио по дням (записываются заранее, пачкой), чат.
5. **Чат-сообщество** (короткая версия ЦЕХа): одна общая группа-форум + потоки. Ветки: «Начни здесь», «Дневник», «Вопросы Алёне», «Объявления и эфиры», ветки по ролям из теста, «Истории участниц». Бот-помощник отвечает только на простое (где/когда), остальное — Алёне.
6. **После 7 дней дневника** → бесплатный разбор с Алёной. Запись — своя в боте (уже есть) + синхронизация с Google Calendar Алёны.
7. **Карточка клиента**: бот собирает тесты + дневник → карточка в формате Алёны. Бот сам шлёт её Алёне; её Custom GPT забирает данные через Action (формат карточки согласуем с Алёной).
8. **Статусы**: кнопки в боте «приняла / был созвон / не пришёл / думает»; оплата Tribute → автоматически «клиент» (лид → клиент).
9. **Программа**: 1 / 4 / 12 сессий, соло и пара — одна цена. Цены даёт Алёна, только на созвоне.

## Что меняется в том, что есть
- 7-дневная цепочка после теста 1 → переделать в дожим до эфира.
- Разбор 20 мин и `vstrecha.py` остаются, вход в них — после дневника.
- Согласие одной галочкой перед дневником + политика конфиденциальности (в т.ч. передача в OpenAI).

## Метрики
`/cifry`: ступени (сайт → запись → пришёл → досмотрел → тест 2 → 7 дней → созвон → оплата), стоимость лида/клиента (UTM). Цель в ₽ — после первых недель.

## Порядок
Минимум сначала: сайт-запись → комната → чат → дожим. Вторая волна: карточка, GPT, Google Calendar. Каждый блок сдаётся Каю экранами до следующего. Тексты: я пишу → Кай → Алёна.

## Решения по черновику сценария (13.09)
- Тест 1 — на сайте ДО записи на эфир (крючок), тест 2 — после эфира.
- Соцпруф — только реальные истории от Алёны (с согласием), не выдумываем.
- Тексты бота: убрать «первые 10 бесплатно / 7 000 ₽»; весь бот и дневник — на «ты».
- Черновик `docs/SCENARII-EFIR-2026-09-13.md`: читает Кай → правки → чистовик → тон-гейт Алёны.

## Нужно от Кая
Ключ сервера в github.com/settings/keys · ключ Render API · токен Cloudflare (зона kydaidy.com) · группа-форум с ботом-админом · проверка, открывается ли сайт из РФ без VPN.

## Разбор: решения 13.09 (выкачено)
- Цена и «первые 10» убраны из бота; разбор бесплатный.
- Вход в разбор и запись — только после недели дневника (админы — всегда); экран «разбор после дневника».
- После дневника: итог недели → 3 вопроса → выбор времени; заявка = срез дневника + ответы.
- Честный дефицит: «N свободных окон, ближайшее…» из реальных слотов. Нужны настоящие окна Алёны (/okna) — иначе ~40 окон = антисрочность.
- Голос везде от лица Алёны.
- Бэклог экрана «разбор после дневника»: ссылка на ближайший эфир; кнопка «спросить Алёну в чате» (когда будут эфир и группа).
